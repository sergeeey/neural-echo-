# Claim

- **Claim (synthetic, falsifiable):** the full-rule detection rate with no wheel effect in the truth rises with the strength of a latent confounder correlated with the wheel, and falls to the nominal null when that confounder is measured and included in the nuisance set.
- **Status:** HYPOTHESIS, EXPLORATORY. Synthetic only.
- **Falsification:** the detection rate with the confounder measured stays above the nominal null, or the rate with no confounder exceeds the nominal null. Either would indicate an implementation problem rather than non-identifiability.
- **Scope:** procedure behaviour under known truth. Not a claim about the real animal.
