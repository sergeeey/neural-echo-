# Architecture Decision Records

ADRs record decisions that are costly to reverse or that a future agent would otherwise re-litigate.

- Format: `NNNN-short-slug.md` with sections Context, Decision, Consequences, Status (`proposed`, `accepted`, `superseded by NNNN`).
- Do not write ADRs for trivial choices.
- An accepted ADR is changed only by a new ADR that supersedes it.
